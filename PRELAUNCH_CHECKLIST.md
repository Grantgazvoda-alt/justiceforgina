# Justice for Gina — Prelaunch Checklist

Prepared July 28, 2026 for the next public version.

## Release rule

Do not merge or publish a release merely because the site builds. A launch requires factual, privacy, legal-context, access, and link checks. Unresolved issues remain labeled unresolved.

## Automated gate

The `Prelaunch QA` workflow checks:

- required public files are present and non-empty;
- the custom domain, sitemap, robots file, and security headers agree;
- critical legal and evidence-limit language remains present;
- local HTML links resolve inside the repository;
- every `target="_blank"` link includes `noopener`;
- primary public pages remain represented in the sitemap.
