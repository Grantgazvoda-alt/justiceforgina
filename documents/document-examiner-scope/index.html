EXPERT MATERIAL

What the report contributes

The report compares reproduced versions and flags document features that should be tested using higher-generation sources.

Supported within scope

  • The controlled archive contains materially different reproduced states of related documents.
  • The expert identified features described as requiring closer review, including a possible overlaid signature and differing notary-page content.
  • Preserved hashes show that selected source-lock files did not change after preservation.

Not established

  • Authenticity of the underlying original documents.
  • Who created any questioned feature.
  • When any change occurred.
  • Whether a change was innocent, administrative, fraudulent, or criminal.

SOURCE-GENERATION LIMIT

A hash authenticates the preserved file, not the historical event.

Cryptographic hashes can show that a digital file remained unchanged after it was preserved. They do not prove when the underlying document was created, who signed it, whether a signature is genuine, or whether the scanned page accurately represents an original.

ORIGINALS

Physical document examination

Paper, ink, impressions, sequence, erasures, toner, line quality, and document construction require authenticated originals and an appropriate expert protocol.

NATIVE SCANS

Earliest-generation digital files

Original scanner captures, embedded metadata, acquisition dates, device identifiers, and file histories can help distinguish copying and assembly pathways.

CUSTODY

Custodian declarations

Each source should identify where the document came from, who possessed it, how it was scanned, and what transformations occurred.

COMPARISON

Version genealogy

Every version should be mapped by page content, signature state, notary state, filename, Bates number, source, and first known appearance.

Responsible-use limit: No public statement should identify a person as having forged, altered, inserted, or fabricated material based solely on the present reproduction-based record.
