# Operation Lantern V4 — Source Supersession and Preservation Policy

## Purpose

The public site must point readers to the strongest current reference without erasing older evidence, historical context, or audit history.

## Governing rule

A file is not "outdated" merely because it is old. An older record may be more important because it is original, contemporaneous, officially filed, signed, or closer to the event.

A public reference may be replaced only when the replacement concerns the same subject and is materially better for the intended public use because it is one or more of the following:

1. more complete;
2. better sourced or cited;
3. corrected and supported by a documented comparison;
4. clearer about provenance, verification, and limitations;
5. safer for public release after privacy and legal review; or
6. byte-identical to the prior file but stored as the better-controlled canonical copy.

## Preservation rules

- Do not delete a superseded, older, draft, or duplicate record solely because the public link changes.
- Preserve the original title, file ID, custody, dates, and known relationships between versions.
- Keep originals and sensitive versions outside the public repository when appropriate.
- Record why the public reference changed and what happened to the earlier source.
- Do not call a newer document "verified" merely because it contains more information.
- Do not merge conflicting versions invisibly. Preserve the conflict and label it.

## Public-reference decision test

Before changing a public link, answer:

1. Is this actually the same subject?
2. What new material or better sourcing does the candidate add?
3. Does it correct an identified error?
4. Is it an exact duplicate? If so, is the proposed copy under better archival control?
5. Does it introduce unsupported conclusions, drafting notes, or private information?
6. Which version is best for the public, press, investigators, attorneys, and experts?
7. Where will the prior version remain preserved?
8. Has the revision history been updated?
